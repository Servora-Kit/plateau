# admin-v1：Admin Web

## 目标

以现有 Vben Ant Design Vue 工程提供唯一管理员使用的轻量总览和 IAM 用户管理界面，接入真实 Admin 后端并完成浏览器端集成验收。

## 需求来源与范围

来源为 [admin-v1 主 PRD](../10-04-admin-v1/prd.md)。对应父需求的全部约束和验收语义均适用，以下映射只划分职责，不缩减父需求。

涉及 `app/admin/web` 及其对 Admin API 的消费；保持独立 workspace、lockfile 和依赖安装。IAM Web 的自助删除、首次改密由 IAM 子任务承担。

| ID | 父需求 | 本任务交付 |
| --- | --- | --- |
| W1 | §1、§8、§9 | 接入真实 IAM 认证与 Admin 会话，展示唯一管理员信息、无权限反馈和退出入口；页面操作与后端自我保护规则一致。 |
| W2 | §14 | 仅保留“总览”和“用户管理”两个一级菜单；轻量总览展示当前管理员信息和用户管理快捷入口，不提供统计图表或演示数据。 |
| W3 | §2、§4、§14 | 用户列表、详情、分页、现有查询条件、资料编辑与状态展示；详情和操作不新增一级菜单，邮箱只读、头像为 URL。 |
| W4 | §3、§5、§6 | 创建用户、管理设密和强制登出 IAM 的界面与结果反馈，表达各自不同的操作效果及首次改密语义。 |
| W5 | §4、§7、§9、§14 | 封禁／解禁、软删除、已删除用户查看、恢复与显式永久删除入口，遵守自我保护、无限期保留和邮箱占用规则。 |
| W6 | §12 | 正确展示人的权限不足、领域冲突、服务调用故障与依赖失败；不泄露内部错误或服务凭据，不将下游故障误判为用户登录失效。 |
| W7 | §13 | 前端检查、构建、启动说明及浏览器 → Admin → IAM 的真实集成验收。 |

## 验收标准

- [ ] AC-W1（W1）：真实管理员经 IAM 登录进入工作区，普通 IAM 用户被拒绝；退出 Admin 后旧会话不可继续访问，IAM 登录不被主动终止；有效 Admin 会话不因 IAM 登出而被页面主动清除。
- [ ] AC-W2（W2）：只展示两个约定的一级菜单，无演示登录、演示菜单或虚构统计；总览显示真实当前管理员信息，可进入用户管理，不新增统计依赖。
- [ ] AC-W3（W3）：查询、分页及详情反映 IAM 真实数据；父需求允许的资料字段可编辑，邮箱不可编辑，头像无需上传功能；变更后可查询到一致结果。
- [ ] AC-W4（W4）：创建表单默认勾选“要求首次登录修改密码”，显式提交最终选择；取消勾选不能被省略或重置。由 Admin 后端编排创建及发信，页面区分创建失败、创建后发信成功、创建后发信失败；发信失败仍显示已创建身份及准确提示，不重复创建。首次改密交互由 IAM 承接。
- [ ] AC-W5（W4）：设置密码和强制登出 IAM 是独立操作，反馈与实际效果一致；不暗示会终止 Admin 或其他应用本地会话，不新增密码交付、邀请或再次强制改密要求。
- [ ] AC-W6（W5）：封禁／解禁、删除／恢复结果与真实状态一致；删除／恢复按当前记录执行，不要求页面 etag。重复删除的 NOT_FOUND 显示为目标不存在或已删除并刷新列表，不显示本次删除成功。已删除用户可无限期恢复或经明确提示确认后永久删除；不显示自动清理倒计时，不提供未软删除账号的永久删除或自助恢复；管理员不能自封禁、自删除。
- [ ] AC-W7（W6）：人的访问被拒绝与服务依赖故障有清晰区分；下游 401/403 不被直接解释为人的登录失效；失败不提示完成，不泄露密码、token、密钥或内部 cause。
- [ ] AC-W8（W7）：前端检查和构建通过，使用真实 IAM 与 Admin 后端在浏览器中覆盖登录、查询、变更、无权限和依赖失败；不得以 mock 页面或接口代替最终验收，提供可复现命令及实际结果。

## 依赖与交付协作

- 依赖 [Admin 后端](../10-18-admin-v1-backend/prd.md) 提供认证、会话、当前管理员及管理操作契约；页面经 Admin 后端访问 IAM，浏览器不持有服务调用凭据。
- 依赖 [IAM 能力补齐](../10-18-admin-v1-iam/prd.md) 完成身份生命周期及 IAM Web 交互；本任务不复制其账号自助页面。
- 页面设计可与后端契约讨论协同推进；真实集成验收须在对应后端能力可用后执行，依赖顺序不由任务树位置替代。
- 本任务执行父需求 §13 的最终浏览器链路验证，IAM 与 Admin 后端子任务提供服务和验证条件，父任务负责最终整体验收评审。
- 页面、组件、状态管理、路由及请求调用链由用户逐项确认后写入本任务设计，不在需求分配时预选实现。

## 约束与不做

- 沿用父任务全部产品约束和排除项；菜单与按钮控制不替代后端认证授权。
- 不新增管理员管理、权限管理、组织、租户、Audit 页面、个人账号中心或统计接口。
- 不新增自动重试、审计接入、跨应用退出联动、密码邮件或管理员接管能力。

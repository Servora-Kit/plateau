# 应用分层规范

适用于 `app/example/service` 与 `app/example/web/`，用于分层和生成契约集成；不作为生产认证授权方案或第二份 API 契约来源。

| 层/职责 | 规范 |
| --- | --- |
| 服务分层与身份边界 | [后端](backend.md) |
| 资源契约与生命周期 | [资源规范](user-crud.md) |
| 页面与状态职责 | [前端](frontend.md) |
| 请求适配与生成 API | [请求](requests.md) |
| 提交与可访问反馈 | [表单](forms.md) |

按变更涉及的层读取对应规范；共通规则引用共享规范，不复制业务资源或接口清单。

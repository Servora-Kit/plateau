# 认证交互生命周期

- 提交前读取必要 URL 状态并校验输入，采用带取消 signal 的单飞请求；按成功、已知领域错误、未认证和基础设施失败更新状态，忙碌期间禁止冲突提交。
- 一次性 URL 值读取后立即用 `history.replaceState` 移除，不放入长期 React 状态、日志或错误文本。
- 已登录页面区分加载、失败、就绪与未认证状态，提供可访问的加载和重试反馈；未认证时进入登录流程。
- 登出在服务端成功确认后导航，不以本地页面跳转代替会话撤销。
- 使用共享表单的 label、错误关联、`aria-busy` 和禁用状态；已知领域错误给出操作提示，网络、超时、403、5xx 使用安全通用文案，不展示原始错误、凭据或 URL fragment。

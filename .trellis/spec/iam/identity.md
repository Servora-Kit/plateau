# 身份与凭据边界

- 身份目录拥有身份事实与认证，不计算业务资源权限；身份标识和唯一性由所属领域定义，不从业务资源规则反推认证身份。
- 邮箱比较值统一 trim、NFC 规范化和大小写折叠；唯一性规则在业务、存储与 API 层一致，不由 transport 决定持久化。
- 密码以带新随机 salt 的 Argon2id PHC hash 持久化，明文不得进入 Repo 或日志。
- 注册、公开重发验证与密码恢复先校验 CAP，再查询账号或执行创建、发信等副作用。
- CAP 通过后的重发验证与恢复请求，对格式错误、未知或不合资格账号返回相同空成功；注册可显式反馈重复账号，不机械套用该抗枚举规则。恢复令牌仅向已激活且已验证身份签发。
- 恢复在同一事务内复验并消费令牌、替换密码和撤销会话；状态与凭据变更同时审查 [会话](sessions.md) 和 [OIDC](oidc.md)，不得拆开安全失效步骤。
- 软删除保留 `login_identifiers` 唯一索引占用，同一事务内撤销人类登录与 OAuth 会话、消费未用验证/重置令牌并清理进行中的授权请求与授权码；恢复与永久擦除仅通过局部 `SkipSoftDelete` 加锁，永久擦除须先处于软删除状态并保留 `actor_type=service` 的访问令牌记录。
- 存在未完成的 `required_actions`（如 `UPDATE_PASSWORD`）时禁止建立登录会话；首次改密与要求改密账号的密码重置均须拒绝新旧密码相同，并在同一事务内校验快照、替换密码、移除动作与轮换 `etag`。

# 平台总体规范

适用于项目目录、能力归属、本地入口和新增应用登记。开始修改前先读对应主题，再加载具体能力或业务规范。

| 主题 | 何时读取 |
| --- | --- |
| [项目结构](structure.md) | 新增目录、模块、应用或生成路径 |
| [规范组织](../../index.md) | 确定应用规范目录、架构与前后端文件归属 |
| [平台边界](boundaries.md) | 判断框架、平台、业务和身份领域职责 |
| [开发约定](development.md) | 端口、命令、工作区与质量检查 |

开发前检查：确认本轮主要 package、跨包影响、当前配置与有效 ADR；发现框架缺陷、能力缺口或可复用的优化需求时，遵循 [Servora 协同迭代](boundaries.md#servora-协同迭代)。

质量检查：路径和注册一致、端口不冲突、生成与手写边界正确，实际运行结果有记录。项目规范目录变化使用 Trellis package 发现检查，业务改动按受影响模块检查。

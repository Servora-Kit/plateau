# 通用思考指南

这些指南帮助开发者识别跨层契约与复用边界；项目的强制规则仍由 [各 package 规范](../index.md) 定义。

| 指南 | 何时读取 |
| --- | --- |
| [跨层检查](cross-layer-thinking-guide.md) | 改 Proto、生成物、身份、资源字段或跨服务／前端的数据流 |
| [代码复用](code-reuse-thinking-guide.md) | 新增 helper、发现重复配置或考虑抽取公共能力 |

开发前明确数据所有者和调用方向；审查时用实际来源验证发现，不把猜测或模板经验当作本项目缺陷。指南不包含 Trellis 上游模板开发、全局 hooks 修改或其他宿主专用流程。

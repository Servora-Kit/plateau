# Admin 架构与范围

Admin 是面向平台管理与运维人员的统一管理应用，管理和查询 IAM、未来 Audit 等基础共享服务。涉及业务微服务时，仅管理其平台基础共享能力与运维事项，不承载具体业务流程或业务租户的管理工作台。

## 领域所有权与接入

Admin 提供管理界面和服务调用编排，被管理服务继续拥有其数据、领域规则与状态转换。用户管理由 Admin 前端请求 Admin 后端，再由后端调用 IAM 的 gRPC UserService；具体接口和授权条件见 [后端](backend.md)。

IAM Web 面向用户本人提供登录与账号自助管理；Admin Web 面向管理人员操作平台资源。两者的职责由服务对象与领域确定，CSR 是渲染方式，不决定应用是否能承担管理界面。

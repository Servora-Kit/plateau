## Scope

Wire-generated entrypoint for the runnable User CRUD reference service.

## Rules

- `main.go` owns process startup/shutdown only; application dependencies come from providers.
- `wire_gen.go` is generated by `just service::example::wire` or `just service::example::gen` and must never be edited manually.
- Verify through `just service::example::run`; do not embed migration, test database, or frontend lifecycle logic in the entrypoint.
